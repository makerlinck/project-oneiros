# 预注册：诊断实验 (a) 新鲜个体难度上限 与 (b) 关掉咬活体

- 日期：2026-11-07
- 状态：预注册（开跑前冻结）

## (a) 新鲜个体难度上限

条件：慢爬坡同一目标世界（base 0.6、60 丛、浆果 0.09、坚果 ×3）；fixed 臂；64 随机创始；8 世界；8192 tick；关闭救援；爬坡冻结在 f ∈ {0.2,0.3,0.4,0.5}（fraction 与毒素强度都用 f）。

判读：
- 新鲜个体在 f ≥ 0.4 能维持（≥6/8 存活且后半段不下降）→ 慢爬坡里的演化没有带来额外能力，确认“进展不明显”。
- 新鲜个体在 f ≤ 0.3 就失败 → 演化确实提高了上限，重新考虑自适应爬坡。

## (b) 关掉咬活体

条件：慢爬坡原样，仅 fixed 臂；关闭咬活体（bite_living_enabled=false，咬活体不造成伤害、不转移物质）；其余同慢爬坡（目标世界、60000 爬坡、70000 总长、救援截止 60000、8 世界）。

判读：
- 救援开始中位后移 ≥0.15 → 乱咬同类是主要瓶颈；下一步讨论动作空间（咬灌木 vs 咬同类）是否拆分。
- 基本不变 → 瓶颈在能量效率/觅食，下一步试突变尺度 ×0.5 与 ×2。
