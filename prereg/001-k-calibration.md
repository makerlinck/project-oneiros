# 预注册：M1 K 标定（第 0 阶段）

- 日期：2026-11-07
- 状态：预注册（开跑前冻结；改动需在 results/ 说明）
- 目的：标定灌木总产量与斑块丰度，使目标世界的承载量 K 落在 N_max 的 40–60%（100–150），并确认“觅食能力有用”的分化。

## 1. 固定条件

- 世界：target（ramp_ticks = 0；设计值常数；温度规则不变）
- 创始动物质 logit 均值：−1（M1 默认创始条件）
- 探针：v3（覆盖率选种、不咬尸体/活体、只咬选定灌木、力度 1.0、档位 0）
- 降级臂：饥饿阈值 h = 0.2（摄入约为 v2 的 50–60%）
- base_metabolism：0.6 与 0.8 倍设计值（0.0012、0.0016）
- 世界数：16/组；tick：8192；关闭重播种；track 开
- 灌木总量：设计总产量 ×{2, 3, 4}
- 加量方式：A = 灌木数量 × k（单丛再生不变）；B = 单丛再生率 × k（数量不变）
- 离开阈值：0.05（主）；0.3（只在 ×3 上做对比）
- 快照：每 64 tick 记录个体位置（用于群聚零模型）

## 2. 组矩阵

- 主矩阵：base {0.6,0.8} × 总产量 {2,3,4} × 方式 {A,B} × 探针 {v3, h0.2} = 24 组
  - 若资源不足，先跑 base 0.6 × 总产量 {3,4} × 方式 {A,B} × 探针 {v3,h0.2} = 8 组，再补。
- 离开阈值对比：base 0.6、总产量 ×3、方式 A、探针 v3，stock-min {0.05,0.3} 两档。

## 3. 记录

- K：后半段（tick ≥ 4096）种群均值，按世界报；K/N_max。
- 创始个体 + 第 1 代 R0（按出生世代截断前的早期世代），以及达到 K/2 之前的增长率。
- 按成熟度拆分的摄入（μ<1 / μ=1）。
- 灌木库存分布（均值、<0.1 比例、按种类）。
- 灭绝比例（最终种群 = 0 的世界数）。
- 每 64 tick 的个体位置快照。

## 4. 验收

1. K 在 100–150（N_max=256 的 40–60%）。
2. 创始个体 + 第 1 代 R0 ≥ 2–3。
3. 降级探针的 R0 < 1（觅食能力必须有用）。
4. 从 4 个创始个体起步时，≥90% 世界不灭绝。
5. 若 f4 过而 f16 不过：K 标定必须包含“坚果丛数”因子，并在 results/ 说明。

## 5. 判读

- 达到验收 → 冻结 M1 世界参数，进入 task-20 长爬坡可演化性。
- 未达到 → 检查是产量不足、坚果集中、还是幼体阶段；按复核规则回用户裁决，不擅自改规格常量。
