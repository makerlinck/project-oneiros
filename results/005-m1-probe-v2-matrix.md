## 2. 三件重要的事

### 2.1 frozen start 下探针能到“替换水平”

- 6 组 frozenstart 的 R0（全体个体）都在 0.98–1.00，种群稳定在 26–101（4 世界），没有灭绝。
- N 支付（新规则）比 B 支付出生更少、种群更小（f16：1765 vs 3194；f64：2605 vs 3566）——符合“从 N 付组织更贵”的预期，但两者都在替换水平附近。
- 出生失败计数巨大（N 支付 no_reserve 23 万–35 万次；B 支付 no_tissue 3 万–7.5 万次），但**按不重复亲代**统计后是 388–926（N 支付）与 86–218（B 支付）个亲代；no_room 仅 8–45 个亲代。这证实了复核意见：逐 tick 的计数不能直接读，必须按亲代统计。
- 中位 max ΣN/θ 在 0.91–0.99，说明个体能稳定接近阈值；这是“世界/规则在宽松起点下可行”的证据。

### 2.2 target 世界 6 组全部灭绝，且远低于模型预测

- R0（全体个体）0.06–0.56；模型预测 f4 + N 支付应有 4–6 胎，实测 0.56。
- 中位 max ΣN/θ 只有 0.15–0.61（<1），即大多数个体一生都没到繁殖阈值；首胎年龄（仅少数）496–830。
- 库存几乎满（0.987–0.997），说明不是“把灌木吃空”，而是**单位时间摄入不足以支付代谢+排泄后留下繁殖余量**。
- 逐配置账本（f4）：harvest 62.4 / metab 39.2 / excretion 19.9 / overflow 1.8；排泄仍占约 32%。f64：harvest 254.8 < metab 256.4，净亏。
- 按复核第四节的判读表：f4 的 R0 远低于 3 → 先对账，不改规格。

### 2.3 关于“毒素是最常见短缺营养”

- track 的“最常短缺”按 N_j/ρ_j 最小统计；frozenstart 里 toxin 出现 667–2567 次，animal 156–1243 次。
- 但毒素的 ρ_T 很小（创始分布 N(−3,1)），N_T 常常为 0，所以 N_T/ρ_T 恒为 0，**这是比例指标的结构性伪影**；死亡事件的营养类型是 plant/animal，toxin 只有 0–135 例。
- 后续把“最常短缺”改为按绝对缺口（ρ_j−N_j）或伤害贡献统计，避免误读。

## 3. 对账的方向（下一步）

1. **静止食物单个体引擎测试**：把创始人放到各自灌木上，探针不移动（u_acc=0），灌木保持可食；测一生胎数，和模型 4–6 对比。
   - 若引擎给出 4–6：差异来自探针移动/寻找食物，是探针效率问题；
   - 若仍 <2：引擎与模型在预算/吸收/消化某处不一致，回头查引擎。
2. 逐个体统计咬灌木次数、摄入质量、排泄、max ΣN/θ 与首胎年龄，和模型逐项对账。
3. 对账通过后再做密度标定：frozenstart 的 K 为 26–101（N_max=256 的 10–40%），低于 §4.2 的 40–60% 目标；target 世界则需要先解决“为什么会灭绝”。
4. 爬坡起点的随机基因组立足点指标（R0≥2 的比例 ≥2%）在 fixed/control 臂上另测；本轮矩阵只测探针。

## 4. 结论

- 探针 v2 在宽松起点（frozenstart）可自持到替换水平，说明规则/引擎在宽松条件下能走通。
- 设计值冻结世界仍不可维持；且与单个体预算模型的预测差距很大，按复核意见这属于**对账问题，不是规格常量问题**——在完成静止食物对账之前不动 θ_repro/繁殖支付/咬收益/基础代谢。
- 繁殖支付从 N 付的改动已生效，B 支付对照仍可用；两种支付都不改变 target 灭绝的定性结论。
