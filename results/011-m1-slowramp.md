## 2. 吃同类，而不是敌友分辨

| 指标 | fixed | 对照 |
|---|---|---|
| 被咬死 / 全部死亡 | 40458 / 65338（62%） | 2438 / 33596（7%） |
| 被咬死中同谱系比例 | 97% | 70% |
| 肉动物质 / 全部摄入质量 | 3874 / 78764（4.9%） | 477 / 19633 |

- fixed 的“咬活体比例更高”是**咬同类变多了**，不是敌友分辨变强。
- 每单位寿命咬灌木次数逐代上升（0.15→0.24→0.33），但对照仅 0.08–0.11；分不清是遗传改进还是世界变难后的饥饿反应，需同一环境比较（实验 c）。
- 对群聚的含义：目前选择压力反对聚集（靠近同类会被吃）。

## 3. 目标世界快照与群聚零模型

- 2048 个采样点（每 64 tick；16 世界）；Clark–Evans R 中位 0.34（p10–p90 0.20–0.47），2 单位内个体对是随机分布的 26 倍。
- 探针无社会行为，这是纯资源驱动聚集。快照已补：灌木位置（每世界一次）与库存（每快照）。
- 演化出社会性聚集必须超过这个基线。
