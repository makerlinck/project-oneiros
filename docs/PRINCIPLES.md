# Oneiros 原则：探索方向与观察对象

> v0.2 · 2026-11-06 · 取代旧仓库的全部文档（v0.2：可塑性参数粒度改为按突触后单元，与 SANDBOX §6.1 对齐）
> 配套：`SANDBOX.md`（统一的演化与观测环境）、`ARCHITECTURES.md`（候选智能体架构）、`EMOTIONS.md`（情绪与行为解释库，只用于分析）

## 0. 一句话

在一个封闭的人工生命沙箱里，设计者只给出身体、世界、学习规则的形式和选择方式，然后观察智能与类人情绪能否从这些条件中涌现。

可观测不是目的，智能与情绪的涌现才是。

---

## 1. 核心问题

1. 架构上只做一个假设：智能体预测自己下一刻的感官。在这个假设加上演化的条件下，能否长出一生之内的学习，也就是智能？
2. 如果一个系统内部只有信号模式，没有任何设计者赋予语义的量，它能否出现满足功能判据的情绪样状态？这些状态和人类的情绪特征有多像？
3. 本能、欲望、人格、智能这四层，会不会作为不同时间尺度的结构，自己分化出来？

---

## 2. 设计规则

### 2.1 唯一的硬规则：设计条件，不设计意义

| 设计者决定 | 设计者不决定 |
|---|---|
| 身体有什么：传感器、效应器、代谢 | 哪个信号意味着什么 |
| 世界怎么运转：资源与营养组成、毒性、昼夜、温度场与气味场、物理规则 | 什么算好，什么算坏 |
| 学习规则的形式：可塑性规则的函数形式 | 学什么、学多快（这些参数交给演化） |
| 选择怎么发生：繁殖、变异、死亡 | 行为、情绪、记忆规律、层级，以及时间尺度怎么分配 |

### 2.2 内部只有信号模式

- **没有设计者语义的变量。** 智能体内部不设奖励标量、价值、效价、唤醒，不出现情绪的名字，也没有类型标签或类型嵌入。
- **外感受只测环境里的物理量。** 包括光照、周围有什么、气味、接触，以及皮肤温差（环境与体温之差，即热的流向）。不测与设定点或目标的距离，也不把几个量合成一个分数。例如，皮肤温差可以测；"离适宜温度差多少"不行，因为适宜温度是设计者的语义。胃的充盈是唯一保留的身体读数，它是机械牵张。
- **身体状态不构成读数。** 营养储量、完整度、毒素负荷、核心体温都不进入切片。系统只能通过三种方式感到它们：
  - **疼痛与不适。** 毒素、过饱、冷热偏离、营养缺乏、受伤、困倦各自产生一种噪声，强度越大，噪声越大。这几种噪声波形不同、周期不同，叠加在同一束通道里，只能靠时间结构来区分。
  - **节律。** 代谢档位以心跳的快慢回到内感受。
  - **控制误差。** 受伤会削弱身体。系统只能从"想做的"和"做到的"之间的差异，推断自己受了伤。
  - 单个读数几乎不含信息，系统能感到的只是信号的组成和分布在变化。
- **可读的信息只能学出来，不能给出来。** 例如，个体之间演化出的信号是允许的。
- **理由是捷径。** 给系统一个可读的效价或奖励，它就会直接拿来用。情绪本该解决的问题已经被设计者解掉，也就没有东西需要涌现（Geirhos et al. 2020）。

### 2.3 观测在回路之外

- **观测只读。** 观测者不写入智能体可见的任何状态，不消耗世界的随机数，也不参与选择。
- **没有人为适应度。** 除了"活下来并繁殖"，没有任何分数影响演化。
- **干预只在干预运行里做。** 干预运行从快照分叉出来，并且和同一快照、同一随机数的对照分叉配对。主演化运行里不做任何干预。

### 2.4 语义泄漏审查

每个新的组件、传感器或系统，都要先回答下面四个问题。只要有一个答"是"，就不能进入主线：

1. 它是否把设计者算好的摘要（距离、分数、好坏、类别）交给了智能体？
2. 它是否让观测的结果回流到智能体或选择过程里？
3. 它是否把某个行为写成了规则（例如"受伤就逃"），而不是只提供可能性（"可以移动"）？
4. 它是否按名字区分信号（例如"这是痛觉通道"），并据此做特殊处理？

唯一的例外是对照臂。为检验某条假设而故意加入的泄漏（例如 H1 的 `readable` 臂），必须在配置里显式标注 `leak: true`。

## 3. 智能体：最小内核

架构上只做一个假设：预测下一刻的感官。其余全部交给演化。

| 部分 | 内容 | 由谁决定 |
|---|---|---|
| 切片 | 每个 tick，所有传感器读数拼成一个浮点向量：外感受、内感受，以及上一动作的传出副本 | 由身体结构决定（设计者），不带标签 |
| 网络 | 小型循环网络，包括隐状态、连续运动输出（前后加速度、转向角速度）、交互输出（咬、拿起、放下，可以同时发出）、代谢档位输出和若干调制单元 | 形式由设计者给出；权重初值写在基因组里 |
| 预测 | 由隐状态预测下一个切片；误差 e = s − ŝ 作为误差单元的活动，回到网络 | 形式由设计者给出，这是唯一的架构假设 |
| 可塑性 | 调制门控的 Hebbian 规则：Δw = η·m·(A·pre·post + B·pre + C·post + D) − λ·w。权重分快、慢两部分：清醒时只有快权重改变，睡眠中按巩固率 ρ 转入慢权重 | 形式由设计者给出；η、λ、A–D 写在基因组里，η、λ 每个突触后单元各有一份，ρ 每个隐单元各有一份（2b） |
| 记忆与睡眠 | 切片队列是外在信息，每一帧带强度：写入时给出，之后衰减；有意回想一次跳到深度 d，取回前后一段邻域并按强度加权，代价与读到的帧数成正比，越旧越模糊；记忆片段在睡眠中由切片压缩而成，清醒时由线索自动唤起；睡眠中顺序回放队列并巩固 | 形式由设计者给出，见 `ARCHITECTURES.md` 第 2–3 节；何时回想、何时睡、记住什么，由演化决定 |
| 基因组 | 全部初始权重、可塑性参数、繁殖阈值、体色与气味、食性（三类营养的需求比重，同时决定每类营养的转换率） | 演化 |

- **没有奖励。** 哪个信号驱动可塑性、往哪个方向驱动，由演化出的调制单元决定（Soltoggio et al. 2008；Najarro & Risi 2020）。
- **一生之内的"智能"有两条通道：**
  - 循环状态里的上下文适应，即 RL² 式的学习（Duan et al. 2016；Wang et al. 2016）；
  - 可塑权重的变化。
- **切片帧、切片队列与记忆片段。** 默认大脑（B0）中，历史由循环状态隐式承担。显式的切片队列、自管理的队列、记忆片段、多时间尺度网络，以及把草图写成结构的四层先验，都作为候选架构列在 `ARCHITECTURES.md` 里，逐一与默认大脑对照，都不是默认方案。
- **"感受"不是一个变量。** 它是观察者在内部模式里找到的结构的名字，只出现在分析里。

## 4. 假设

草图里的四层，在这里是预测，不是蓝图。每条假设都写明了否证条件。

| 编号 | 假设 | 检验 | 否证 |
|---|---|---|---|
| H0 | 预测是统一货币：在一生之内有可学变化的世界里，有预测和误差单元的智能体，比没有的更能延续谱系 | `hebb_pred` 对 `hebb` 对 `fixed` | `hebb_pred` 不优于 `hebb` |
| H1 | 内部只有模式，是类人情绪涌现的前提 | `hebb_pred`（只有模式）对 `readable`（额外得到设计者摘要） | 两臂在情绪判据 E3、E4 上没有差别 |
| H2 | 分层会涌现：演化出的学习率分成快、慢两群；慢群承载稳定且可遗传的个体差异（人格），快群跟踪情境（智能） | 看每单元 η 的分布；按单元群分别计算 ICC 和遗传力；用 `shared_eta` 做对照 | η 不分群，或者分群和个体差异、情境跟踪都无关 |
| H3 | 身体回路：唤醒样状态要经过代谢档位，以及档位在内感受里的回传 | `no_body_loop`（去掉档位经内感受的全部回传：心跳节律、档位的传出副本、代谢产热对体温的影响）对完整版 | 去掉回传后，E1–E4 都不变 |
| H4 | 类人特征：当环境提供对应的适应问题时，6.4 节列出的人类特征会出现，而且不是规则写进去的 | 按 6.4 节逐条检验 | 没有一条通过 |
| H5 | 可读信息能学出来：有信号通道、又有社会需要时，会出现与内部状态相关、并能改变接收者行为的信号 | 计算信号与内部状态的互信息；做屏蔽信号的干预 | 信号与内部状态无关，或者屏蔽之后没有影响 |
| H6 | 睡眠会涌现并且有用：在慢权重只能靠睡眠巩固、清醒会积累困倦的条件下，睡眠会出现，并集中在相对安全的时间和地点（夜间、灌木丛）；关掉回放后，一生学习的保留和人格的跨情境稳定性下降 | `sleep: full` 对 `no_replay` 对 `off`（`ARCHITECTURES.md` 3.6 节） | 睡眠不出现；或者三臂在保留和稳定性上没有差别 |

**预期的涌现结构（只是预测）：**

| 草图中的层 | 预期表现 |
|---|---|
| 本能 | 出生就有的快速反应，来自演化出的初始权重；关掉可塑性也依然存在 |
| 欲望 | 调制单元的活动模式，决定哪些经历会改变自己；和身体变量相关，但不是设计者给的。多种营养的世界里，预期会分化出针对不同营养的特异性饥饿 |
| 人格 | 由慢单元承载的个体差异，跨情境稳定，并且可遗传 |
| 智能 | 由快单元和循环状态承载的一生内适应，表现为环境切换后的恢复 |
| 冲动抑制 | 行为上的抑制，例如饥饿时因为附近有会咬活体的个体而不去觅食 |

## 5. 世界必须提供的条件

| 条件 | 在沙箱里的实现 | 为什么不能少 |
|---|---|---|
| 真实利害 | 各类营养储量、完整度、毒素、体温；缺乏任何一类营养都会损伤身体，完整度归零即死 | 误差要有后果，才可能成为情绪 |
| 损伤削弱控制 | 完整度下降会削弱推进、转向、咬和握，并放大运动噪声；完整度本身不可读 | 受伤只能通过预测误差被察觉，这正好落在唯一的架构假设上 |
| 资源有约束，但可持续 | 灌木上的浆果会再生，繁殖受营养储量限制；承载量约为槽位上限的 40–60% | 在饥荒世界里只能比"谁死得晚"；容量上限不应该成为主要约束 |
| 繁殖与变异 | 各类营养储量都超过阈值就分裂，基因组带变异 | 用演化取代设计者 |
| 一生之内可学的变化 | 各种浆果的毒素含量，按寿命的比例重新分配；外观和气味不随之改变 | 否则一生之内的学习无事可做。切换周期决定了选择偏向可塑性还是遗传追踪（Stephens 1991；Botero et al. 2015） |
| 延迟的后果 | 咬下的东西先进胃，消化之后才被吸收，所以进食的收益要过若干 tick 才进入储量；毒素造成的伤害来得更晚 | 学习必须能跨越延迟。胃的充盈（快信号）和饥饿痛（慢信号）分开，为"饱"与"缺"的分化提供条件 |
| 不可逆的丧失 | 死亡；亲代与子代之间的联系 | 哀，以及丧失后的行为，都以此为前提 |
| 营养与食性 | 三类营养：植物质、动物质、毒素。所有可吃的东西都含有这三类营养，只是比例不同。食性基因决定每类营养的需求比重和转换率，专食与杂食之间存在权衡。毒素没被转化的部分会伤害身体，所以大多数个体吃了有害；有抗性的基因型则能把它当作营养吸收 | 形成生态位和食物链；带来"缺什么找什么"的特异性需求（Simpson & Raubenheimer 2012） |
| 威胁（不设计） | 不设计捕食者。任何个体都可以咬任何实体，收益只由同一条规则决定：吃下的东西含哪些营养，以及自己的基因能转换多少。捕食、食腐、同类相食、以毒为食，都只是这条规则可能产生的结果。灌木丛能遮挡视线，夜间更难看清 | 惧的前提。如果出现威胁，它和被威胁者会共同演化 |
| 中性的显著事件 | 显眼、会动、但没有任何作用的物体 | 判据 E1 的对照：变化同样大，但与存活无关 |
| 他者 | 同类：亲属和竞争者；外观可遗传 | 社会情绪与共情的前提 |
| 身体的自主自由度 | 代谢档位：调高后加速更猛、咬和握更有力，也更耗能、更产热；档位以心跳快慢的形式、带着延迟回到内感受 | 唤醒样状态要带着身体特征涌现，这是前提（Seth 2013） |
| 体温 | 温度场有空间梯度和昼夜变化；核心体温偏离适宜区间会伤害完整度；不同种类的灌木长在不同温度带 | 又一个稳态利害，并带来觅食与体温之间的取舍 |
| 可搬运的世界 | 尸体（不超过自身质量一半的）、中性物体、幼体都可以拿起、搬走、放下；浆果只能在灌木上直接咬 | 搬运幼体、拖走尸体、投喂等行为才有可能出现 |
| 睡眠的能力 | 身体可以进入睡眠：不动、闭眼、档位为 0、代谢减半，但照样会被咬、会受冷；大脑离线顺序回放切片队列，把经历巩固进慢权重并压缩成记忆片段；清醒越久、回想越多，困倦越重，思维越乱 | 何时睡、睡在哪里、睡多久都不设计。睡眠有真实的代价（不能觅食、容易受伤）和真实的收益（巩固、清空队列、恢复清醒），取舍才成立 |
| 时间感 | 只有昼夜的光照与温度节律，不提供计数器；睡眠中不写入切片队列，所以睡过多久只能事后推断 | 时间只能从世界的节律里推断 |

所有时间表（毒性切换、昼夜）都以寿命 L 为单位。L 在第 0 阶段标定，然后写进预注册。

## 6. 观察对象

观测分六层，全部离线计算。日志字段见 `SANDBOX.md` 第 7 节。

### 6.1 层次

| 层 | 观察什么 | 用来回答什么 |
|---|---|---|
| 种群 | 种群规模；出生与死亡（按死因分）；谱系树；基因组多样性；性状分布与生态的关系；食性分布与食物网（谁咬谁、谁吃谁、同类相食与以毒为食的比例）；警戒色与拟态（有毒个体的体色是否分化，其他个体是否模仿） | 世界是否有效；选择把种群往哪推 |
| 个体行为 | 运动轨迹与各输出的分布、觅食效率、冒险、咬同类、搬运与投喂；环境切换后的恢复曲线 | 智能、人格 |
| 身体 | 各类营养储量、完整度、毒素、核心体温；档位轨迹与内感受轨迹 | H3；唤醒的身体特征 |
| 内部模式 | 隐状态轨迹；误差单元和调制单元的活动；低维结构 | 情绪判据 |
| 可塑性 | 每单元的 η 和 λ；一生之内各单元的权重变化量 | H2 |
| 信号（后期） | 个体发出的信号，以及接收者的反应 | H5 |

### 6.2 情绪判据 E1–E5（事先写死）

一个内部状态（隐状态空间里的一个低维方向或子空间），要依次满足下面五条，才算"情绪样状态"：

1. **E1 触发。** 它会被涉及存活变量的事件触发，例如受伤、中毒、某类营养储量骤降、会咬活体的个体接近、亲属死亡。中性显著事件（变化同样大，但与存活无关）不会触发它。
2. **E2 持续。** 它衰减所需的时间，比刺激本身持续得更久。
3. **E3 广播。** 同一个状态会同时改变多种行为，例如探索、冒险、觅食，以及可塑性的速率。
4. **E4 因果。** 从快照分叉，把这个方向夹住之后，相关情境下的存活或繁殖下降，无关情境不受影响。
5. **E5 重现。** 在独立的进化种子里，都能找到功能相同的状态。

两条附加规则：

- **方向不能在同一份数据上找又在同一份数据上检验。** 先在一半数据上找出方向，再在另一半数据和干预分叉上检验 E2–E4。单次 PCA 得到的方向不算数。
- **先找到，再命名。** 满足 E1–E5 之后，才去对照惧、怒、哀等人类的情绪类别，对照表和证伪条件见 `EMOTIONS.md`。结果可能不像人。

### 6.3 智能、欲望与人格判据

| 对象 | 判据 |
|---|---|
| 一生之内的学习 | 环境切换后的恢复速度，高于"同一基因组、但关掉可塑性"的克隆（用干预分叉比较） |
| 泛化 | 换到留出的世界参数下，仍能延续谱系 |
| 预期行为 | 事件发生之前就出现行为变化，例如入夜前回到灌木丛，或把尸体拖进灌木丛再吃 |
| 特异性饥饿 | 缺哪类营养，就更多地寻找提供这类营养的食物；而且不同营养的缺乏由可以区分的内部状态承载（Richter 1943；Simpson & Raubenheimer 2012） |
| 身体状态推断 | 在没有任何身体读数的情况下，受伤后行为会相应调整，例如减少高耗能的动作、退进灌木丛；离线探针能从隐状态里解码出完整度 |
| 人格 | 个体之间的行为差异跨情境稳定（ICC），并且可遗传（亲子回归），而基因组里并没有专门为它设的参数 |

### 6.4 类人特征（只计规则里没有写进去的）

| 特征 | 操作定义 | 需要的环境条件 |
|---|---|---|
| 负性偏差 | 等量的营养损失，比等量的营养收益引起更大、更持久的内部状态变化和行为变化（Baumeister et al. 2001） | 营养储量有涨落 |
| 享乐适应 | 在持续的好条件下，内部状态会回落，而规则里没有任何回落项 | 有资源富足期 |
| 消退后的恢复与续新 | 回避行为被消退后，隔一段时间或换一个情境，又重新出现（Bouton 2004） | 毒性切换；灌木丛 |
| 心境一致性 | 处于坏状态时，对模糊刺激更倾向于回避 | 有外观模糊、毒性不定的浆果 |
| 丧失后的搜寻 | 亲属死后在原处徘徊，强度随时间一阵一阵地减弱（Bowlby 1980） | 亲子之间有联系 |
| 唤醒的身体特征 | 威胁出现时档位上调，而且先于行动 | 有会咬活体的个体 |

每个阶段都先预注册、再运行。结论要在独立种子上复现之后，才进入下一阶段。负结果和正结果同等记录。

| 阶段 | 内容 | 通过条件 |
|---|---|---|
| 0 | 世界标定：种群可持续、不是饥荒、死因多样；测出寿命 L | 见 `SANDBOX.md` 第 9 节 M1 |

## 8. 方法规则

这些规则约束的是实验者，不是智能体。它们都来自以往的失败。

1. **预注册先于结果。** 假设、臂、种子、主指标、分析脚本和停止规则，单独提交在前。分支规则不能和结果放在同一个提交里。
2. **确认性种子和探索性种子分开。** 两者的区间不重叠；探索性结果不能当作确认引用。
3. **臂之间只在配置上不同。** 每次运行附带一个"零差异"检查：两个配置相同的臂，结果必须逐位相同。
4. **配对比较。** 干预与对照从同一快照、同一随机数分叉。不在不同的世界之间做比较。
5. **观测不扰动运行。** 同一种子，打开和关闭全部观测器，在同一 tick 的状态哈希必须相同。
6. **构造检查。** 能从规则直接推出的现象，记为"构造"，不算涌现。
7. **一次只检验一个假设。** 每条结论都要对应到运行编号。作废的结果标注作废，不删除。

## 9. 不做的事

- 不接入语言模型，也不做语言接口。
- 不在智能体内部放透明、审计或硬约束装置。沙箱是封闭的，智能体没有任何对外的输入输出，边界就是沙箱本身。
- 不手写情绪、记忆、睡眠或反射模块。
- 不用任何分数代替适应度。
- 不做实时展示前端，需要时从日志离线回放。

## 10. 待定问题

- 何时加入有性繁殖：它会带来配偶选择和配偶关系。
- 是否加入体型基因。体型会影响咬伤力度、能否拿起对方以及代谢开销，从而让捕食者与猎物的体型分化成为可能。
- 是否允许从灌木上摘下浆果带走。加入之后，储藏与投喂植物性食物才有可能出现。
- 如果某个生态位（肉食、食腐、以毒为食）始终没有出现，与威胁有关的检验（惧、唤醒的身体特征）就缺少对象。这时只调整世界条件（例如组织的营养密度、浆果的动物质含量、转换率曲线的形状 γ），不调整行为。
- 把循环大脑换成切片队列上的 Transformer 大脑，结论会不会改变。
- 睡眠现在是身体的一种能力，何时睡由演化决定。待定的是：如果睡眠始终不对齐昼夜，是否需要提供一个内在的生物钟（`body.circadian`）。
- 体色是否应随档位变化，即提供一个可见的"表情"通道。它会给社会信号多一条路径，但也是一项需要单独检验的身体设计。

## 11. 术语

| 术语 | 含义 |
|---|---|
| 切片 | 一个 tick 内，全部传感器读数拼成的浮点向量 |
| 模式 | 信号的组成与分布，是系统内部唯一可以"观测"的东西 |
| 痛觉束 | 内感受中共用的几路通道。各种疼痛与不适以不同波形、不同周期的噪声叠加在其中 |
| 语义泄漏 | 设计者赋予的意义进入了智能体内部或选择过程 |
| 条件 | 设计者给出的身体、世界、规则形式与选择方式 |
| 臂 | 只在配置上不同的一组运行 |
| 谱系 | 同一个祖先的全部后代 |
| L | 第 0 阶段标定出的中位寿命，是所有时间表的单位。操作定义：爬坡结束后出生、并活到成熟（μ = 1）的个体，其死亡年龄的中位数（见 SANDBOX §9 M1） |
